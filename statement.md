# Project Statement

## Project Title
Campus Academic Management System

## Problem Statement
Managing student academic information manually can make it difficult to organize student details, marks, attendance, and performance reports. Teachers and students need a simple system that can provide academic information in an organized manner.

## Scope
The project provides a console-based academic management system for storing and displaying student and teacher information, subjects, marks, attendance, and academic results.

## Target Users
- Teachers
- Students
- Academic administrators

## High-Level Features
1. Student management
2. Teacher information management
3. Subject management
4. Marks management
5. Attendance management
6. Performance and result reporting

## Objectives
- Reduce manual academic record management.
- Organize student academic information.
- Calculate marks percentages and grades automatically.
- Calculate attendance percentages and eligibility.
- Generate a consolidated student performance report.
- Demonstrate Java OOP concepts in a practical application.

## Functional Requirements
- The system shall display a main menu.
- The system shall provide Teacher and Student portals.
- Teachers shall be able to add students.
- The system shall display student and teacher details.
- The system shall store marks for subjects.
- The system shall calculate percentages and grades.
- The system shall calculate attendance and eligibility.
- The system shall generate student performance reports.

## Non-Functional Requirements
- Usability: menus and messages should be easy to understand.
- Reliability: invalid numeric input should not crash the program.
- Maintainability: functionality is divided into separate Java classes.
- Performance: in-memory ArrayLists provide fast access for the small dataset.
- Validation: marks and attendance values are checked before storage.
- Scalability: additional modules and persistent storage can be added later.

## Technologies
Java, OOP, ArrayList, exception handling, VS Code and GitHub.
