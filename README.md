# Campus Academic Management System

## Overview
The Campus Academic Management System is a Java-based console application for managing basic academic information of students, teachers, subjects, marks, attendance, and performance reports.

## Features
- Teacher portal
- Student portal
- Add and view students
- View teacher details
- Store subjects and marks
- Calculate marks percentage
- Calculate attendance percentage
- Check attendance eligibility
- Generate student performance reports
- Calculate grades and pass/fail status
- Input and data validation

## Technologies / Tools
- Java
- Object-Oriented Programming
- ArrayList
- Exception handling
- VS Code / Command Prompt / PowerShell
- GitHub

## Project Structure
- `Main.java` - Main menu and program flow
- `AcademicSystem.java` - Manages academic data
- `User.java` - Base user class
- `Student.java` - Student class
- `Teacher.java` - Teacher class
- `Subject.java` - Subject information
- `Marks.java` - Marks and percentage calculation
- `Attendance.java` - Attendance calculation and eligibility
- `Result.java` - Grade and pass/fail calculation
- `ReportGenerator.java` - Student performance report

## How to Run
Open the `src` folder in terminal and run:

```text
javac *.java
java Main
```
